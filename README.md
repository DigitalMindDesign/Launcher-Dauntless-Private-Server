# Launcher Dauntless — serveur privé

Launcher Windows pour jouer à Dauntless 1.4.4 sur un serveur privé [Dauntless Revived](https://github.com/mixutin/dauntless-revived), entre amis, via Tailscale. Par Digital Mind.

## Télécharger

Prends l'installeur `Installer-Launcher-Dauntless-x.y.z.exe` dans la dernière [release](../../releases/latest).
Une fois installé, le launcher vérifie lui-même les nouvelles versions à chaque démarrage (page **À propos** → **Rechercher une mise à jour**).

Chaque release contient aussi :

- `SHA256SUMS.txt` : les empreintes des fichiers (le launcher vérifie l'installeur avant de le lancer) ;
- le code source du launcher n'est pas publié : il est fourni sur demande à toute personne qui a reçu le launcher (licence AGPL-3.0, comme le projet dont il intègre des composants) ;
- la documentation et les mentions de licences.

## Ce que fait le launcher

- **Jouer** : récupère le jeu, connecte Tailscale, trouve les serveurs de tes amis, crée ton compte.
- **Héberger** : transforme ton PC en serveur privé en un clic (Dauntless Revived), avec sauvegardes automatiques toutes les 30 minutes.
- **Admin / Personnages** : invitations, joueurs, progression et inventaire, avec le catalogue complet des objets du jeu (noms FR/EN, icônes, valeurs des cellules par niveau).

Outil non officiel, sans lien avec Phoenix Labs ni avec l'équipe Dauntless Revived. Dauntless est une marque de ses propriétaires. Le launcher ne contient pas le jeu.
